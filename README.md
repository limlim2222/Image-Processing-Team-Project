# 영상처리 팀 프로젝트: 이미지 기반 주차 공간 탐지

## 프로젝트 개요

본 프로젝트는 영상처리(Image Processing) 기법을 활용한 이미지 기반 주차 공간 탐지 시스템을 구현하는 것을 목표로 합니다.
고정된 카메라로 촬영된 주차장 이미지를 입력으로 받아 주차 칸의 위치를 자동으로 검출하고, 각 주차 칸이 **비어 있는지 또는 차량이 주차되어 있는지**를 판별합니다.

센서 기반 주차 관리 시스템에 비해 비용이 저렴하고 설치가 간단하여, 대규모 야외 주차 환경에 적용 가능성이 높은 컴퓨터 비전 기반 접근 방법을 다룹니다.

- 대학원 영상처리 수업 팀 프로젝트 (2022)


## 프로젝트 배경 및 목적

대형 주차장의 경우 빈 주차 공간에 대한 정확한 정보 제공은 사용자 편의성과 교통 혼잡 감소에 중요합니다.
기존의 센서 기반 시스템은 주차 칸마다 센서를 설치해야 하므로 비용이 높고 유지 관리가 어렵습니다.
본 프로젝트에서는 **카메라 영상만을 이용한 주차 공간 탐지 방법**을 구현하고, 날씨와 조명 조건이 달라지는 실제 주차장 이미지에서 그 가능성을 검증하고자 하였습니다.


## 전체 시스템 구성

시스템은 두 단계로 구성됩니다.

1. **주차 칸 검출 (Parking Space Detection)**
   차량이 없는 배경 이미지에서 주차선을 찾고, 주차선의 교차점을 이용해 주차 칸별 영역(Bounding Box)을 생성합니다. 생성된 영역은 CSV 파일로 저장됩니다.

2. **빈 공간 / 점유 공간 판별 (Occupancy Classification)**
   배경 이미지와 현재 이미지를 비교해 변화가 생긴 영역(차량)을 찾고, 1단계에서 만든 주차 칸 영역과 비교해 칸별 점유 여부를 판단합니다.


## 1. 주차 칸 검출 (`parkingspace_detection.py`)

주차장 바닥과 주차선을 구분하고, 주차선의 교차점을 기준으로 주차 칸을 나눕니다.

### 처리 과정

1. **배경 이미지 로드**
   차량이 없는 주차장 이미지를 입력으로 사용합니다.

2. **K-means 색상 분할 (K=3)**
   이미지의 색상을 3개 그룹으로 나눠 아스팔트 바닥, 흰색 주차선, 그 외 영역을 구분합니다. 원본 이미지에서 바로 에지를 찾으면 바닥의 질감과 얼룩까지 검출되기 때문에, 먼저 색상을 단순화했습니다.

3. **Sobel 필터를 이용한 기울기 계산**
   분할된 이미지에 X 방향과 Y 방향 Sobel 필터를 적용하고, 두 결과 중 큰 값을 합쳐 주차선의 경계를 강조합니다. 일정 값보다 약한 기울기는 제거해 노이즈를 줄였습니다.

4. **확률적 Hough 변환(HoughLinesP)을 이용한 직선 검출**
   기울기 이미지에서 주차선에 해당하는 선분을 검출합니다. 최소 선 길이와 허용 간격을 조정해 짧은 노이즈 선분은 제외하고, 끊어진 주차선은 하나의 선분으로 이어지도록 했습니다.

5. **Bentley–Ottmann 알고리즘을 이용한 교차점 계산**
   검출된 선분들의 교차점을 계산합니다. 교차점은 주차 칸의 모서리에 해당합니다. 같은 지점 근처(15픽셀 이내)에서 여러 개가 검출된 교차점은 하나로 합쳤습니다.

6. **주차 칸 영역 생성 및 저장**
   교차점을 주차 줄 위치에 맞춰 정렬하고, 이웃한 교차점 사이를 하나의 주차 칸으로 보고 바운딩 박스를 만듭니다. 폭이 지나치게 넓거나 좁은 영역은 제외했으며, 결과는 `data/` 폴더에 CSV 파일로 저장됩니다.


## 2. 빈 공간 / 점유 공간 판별 (`cars_emptyspace_detection.py`)

차량이 없는 배경 이미지와 현재 이미지의 차이를 이용해 차량이 있는 영역을 찾는 **배경 차분(Background Subtraction)** 방식을 사용했습니다.

### 처리 과정

1. **현재 이미지와 배경 이미지 로드**

2. **전처리**
   두 이미지에 샤프닝 필터를 적용해 경계를 선명하게 한 뒤 Grayscale로 변환하고, Gaussian Blur(5×5)로 작은 노이즈를 줄였습니다.

3. **배경 차분 및 이진화**
   두 이미지의 절대 차이를 계산하고, 임계값(45)을 기준으로 이진 영상을 만들어 변화가 생긴 영역만 남깁니다.

4. **형태학 연산 (Opening)**
   Opening 연산으로 이진 영상의 작은 점 노이즈를 제거했습니다.

5. **연결 요소 분석을 이용한 차량 영역 검출**
   `connectedComponentsWithStats`로 변화 영역을 덩어리 단위로 나누고, 크기가 너무 작거나 큰 영역은 제외해 차량 후보만 남겼습니다.

6. **주차 칸별 점유 여부 판단**
   1단계에서 저장한 주차 칸 바운딩 박스와 차량 후보 영역이 겹치는 비율을 계산합니다. 주차 칸 면적의 **80% 이상이 겹치면 점유(Occupied)**, 그렇지 않으면 **빈 공간(Empty)**으로 판단해 화면에 다른 색으로 표시합니다.


## 전처리 방법 비교

처리 방법을 정하기 위해 여러 전처리 방법을 비교했으며, 결과 이미지는 `results/` 폴더에 정리했습니다.

- **블러 비교**: Gaussian, Median, Bilateral
- **기울기 비교**: X 방향, Y 방향, X·Y 합성
- **형태학 연산 비교**: Opening, Closing
- **K-means 분할 결과**
- **Bentley–Ottmann 교차점 검출 결과**
- **PKLot 이미지에 대한 검출 결과**


## 데이터셋

본 프로젝트는 **PKLot Dataset**을 활용하였습니다.

* 총 12,416장의 주차장 이미지
* 맑음, 흐림, 비 등 다양한 날씨 조건 포함
* 주차 공간의 빈 공간 / 점유 상태에 대한 라벨 제공


## 한계점

* 주차 칸 검출 시 주차 줄의 위치를 특정 카메라 화면에 맞춰 설정했기 때문에, 다른 주차장이나 다른 카메라 각도에 적용하려면 값을 다시 조정해야 합니다.
* 배경 차분 방식은 그림자나 조명 변화가 큰 경우 차량이 없는 곳도 변화 영역으로 검출될 수 있습니다.
* 날씨와 시간대가 바뀌면 배경 이미지도 그 조건에 맞게 준비해야 정확도가 유지됩니다.


## 폴더 구조

```
TermProject/
├── parkingspace_detection.py        # 주차 칸 검출
├── cars_emptyspace_detection.py     # 빈 공간 / 점유 공간 판별
├── isect_segments_bentley_ottmann/  # Bentley–Ottmann 교차점 계산 (외부 라이브러리)
├── data/                            # 주차 칸 바운딩 박스 CSV
├── test_images/                     # 테스트 및 배경 이미지
├── results/                         # 처리 과정 및 결과 이미지
└── requirements.txt
```


## 실행 방법

```
pip install -r TermProject/requirements.txt
cd TermProject

# 1. 주차 칸 검출 (data/ 폴더에 CSV 생성)
python parkingspace_detection.py

# 2. 빈 공간 / 점유 공간 판별
python cars_emptyspace_detection.py
```

* 입력 이미지와 CSV 파일 경로는 각 파일 하단에서 수정할 수 있습니다.
